# CashPay All Showcase Website

Ce site est la vitrine technologique officielle de CashPay All. Il est conçu pour être déployé sur `https://cashpay-all.com`.

## Architecture
- `index.html` : Point d'entrée principal.
- `/css` : Styles personnalisés et animations.
- `/js` : Interactions utilisateur.
- `/public/images` : Dossier destiné à recevoir vos PNG détourés (sans cadres) et les logos.
