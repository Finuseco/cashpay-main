# Developer source-code display

The source-code section in `developpeurs.html` retains its existing example and syntax colors. `js/code-demo.js` reveals the text as a computer monitor demonstration. It sends no network requests and contains no real keys.

Play/pause works with keyboard and touch. Labels follow the site's French/English language switch. Reduced-motion users see the full static code. Typing stops while the page is hidden or the monitor is outside the viewport.

Verified at 360px and 1440px, with reduced motion, pause and language switching. A mobile grid minimum width was corrected to prevent horizontal page overflow.
